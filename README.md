# PSE Cartographer

Live J-space cartography of a local GGUF model, on the PSE-A engine: layer by layer, the concepts a model holds ready to say. Two editions: PSE Cartographer (Qwen, Llama, Mistral) and PSE Cartographer Max (eight model families, plus mixture-of-experts routing).

- **Download:** <https://www.zeravatech.ca/downloads/model-tools/>, for Ubuntu and Windows, with SHA-256 checksums
